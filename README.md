# Cardápio Online

Este é um modelo de cardápio online para pequenas empresas, desenvolvido por mim durante um minicurso. Este projeto foi vendido ainda durante os meus primeiros 7 meses de programação. Ele me permitiu aprimorar meus conhecimentos em HTML, CSS e JavaScript, além de explorar bibliotecas e frameworks como jQuery, Bootstrap, Animate.css, Wow.js e FontAwesome. A aplicação é totalmente funcional e responsiva. Futuramente, pretendo refazer este projeto utilizando React e TypeScript, tecnologias que tenho estudado atualmente.

## Deploy

A aplicação está disponível em: [Cardápio Online](https://cardapio-online-snowy.vercel.app)
